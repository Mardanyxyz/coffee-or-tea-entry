# One Letter: Coffee or Tea

Coffee or tea — the whole debate, settled in a single letter.

This entry answers **A, for coffee**. Tea is a lovely, civilised
afternoon; coffee is the fuel that keeps the build going at 2 a.m.
When the choice is one letter, pick the one that smells like a fresh
pot and tastes like getting things done.

`main.ts` writes exactly that one letter — `A`, no newline, no
punctuation, nothing else — to `/output/entry.txt`, then reads the
file back and refuses to finish unless it matches byte for byte.

## Run it

```sh
node main.ts
```

It prints the letter it wrote and exits 0. `/output/entry.txt`
will hold exactly one byte: `A`.
